# External Asset Sources (Kid-safe, release-friendly)

Use these sources to download more robot/space assets with clear licenses.
Always verify each pack license before shipping.

## Free / Open

- Kenney: https://kenney.nl/assets
- OpenGameArt (filter CC0 / CC-BY): https://opengameart.org
- Itch.io free game assets: https://itch.io/game-assets/free
- Icons8 Ouch illustrations: https://icons8.com/illustrations

## Paid / Premium

- Itch.io premium assets: https://itch.io/game-assets
- CraftPix: https://craftpix.net
- Envato Elements: https://elements.envato.com/graphics/game-assets

## License Checklist

1. Confirm commercial usage is allowed.
2. Check attribution requirements.
3. Save source URL and license text into your project docs.
4. Keep purchase receipts for paid packs.
